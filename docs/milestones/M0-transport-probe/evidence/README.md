# M0 evidence index (offline candidate)

Generated by the offline probe; all files here are sanitized and contain no
credentials, device identifiers, keys or private content.

| File | Purpose |
|---|---|
| `offline-report.md` / `.json` | Machine-checked A01-A28 matrix, environment, dependency/fixture hashes, BLOCKED L/H rows, security limitations, known issues, exact re-run context. Generated by `make verify-m0`. |
| `snapshot/` | Candidate working-tree evidence: branch, HEAD, dirty status, SHA-256 of every `cmd/` + `internal/` Go file. No commit/push was authorized, so the candidate is this uncommitted working tree. |
| `usage.md` | Exact commands, prerequisites, live/hardware config shapes, re-run steps, implementation scope and known gaps. |
| `compatibility-offline.md` | Per-item compatibility findings: what the offline simulation proves versus what remains hardware/cloud dependent. |
| `live-report.md` / `hardware-report.md` | Sanitized **BLOCKED** evidence written by the gated authorized entries when no authorization/config exists. |

Acceptance decision is not made here. The specification still records "待批准";
the specification owner/referee and an independent acceptance agent decide.
