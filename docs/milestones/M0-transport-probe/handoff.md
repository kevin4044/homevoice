# M0 编码与验收交接

规格版本：`M0-v0.1`。当前状态为待批准草案，本轮仅编写规格，不启动编码。

## 给编码负责人的任务

批准后可使用以下任务描述：

> 仅在Homevoice新仓库中实施M0-v0.1 MQTT+UDP隔离探针。先阅读根AGENTS.md和本交接包全部规格、协议、验收、任务及环境清单。旧项目仅由规格负责人研究，不得访问或间接下载。自行决定串行/并行与集成，先补测试，再实现；不改验收标准、外部协议或扩大产品范围。离线实现不依赖真实秘密。缺少硬件/云授权时完成可执行的离线部分并报告阻塞。最终提供固定候选版本、逐项测试证据、兼容性与安全限制，供独立验收和裁判检查。

## 执行前检查

- 工作区是否包含用户变更、规格是否已经批准。
- 当前分支是否为专用实现分支；不要混入规格草案或其他阶段代码。
- 根规则、fixtures、acceptance均能从本仓库读取。
- Go/编译器/原生依赖是否具备，公开依赖获取是否获准。
- 是否具备实际委派子Agent的工具能力；不能假定不同产品可自动调度。

## 授权分层

| 层级 | 需批准的内容 |
|---|---|
| D：规格 | 本文档包定稿；当前用户请求只授权规格编写和建分支 |
| C：离线编码 | 新仓库代码/模拟测试/公开依赖与预算；待批准 |
| L：云服务 | 一个指定模型/语音/MCP配置、读取范围、费用与次数上限；待批准 |
| H：硬件 | 指定设备、隔离网络、配置变更/恢复、录音/播放/通知范围；待批准 |
| G：Git发布 | 提交、推送、PR；本轮未授权 |
| P：生产与敏感动作 | 公网部署、家庭迁移、OTA、敏感家电；明确不在M0默认授权 |

环境变量或配置开关仅表达运行意图，不替代用户授权。

## 运行与配置

编码阶段实现offline/live/hardware入口后，记录具体启动参数和最小示例，不让后续Agent猜命令。

敏感测试配置存放新仓库忽略的`local/`中，不提交密码、私钥、家庭地址、真实设备标识。报告和音频缓存默认也在忽略目录，完成后按获准留存规则清理。仓库内只交付脱敏结果。

真实测试开始前填写[环境清单](compatibility.md)，确认原配置恢复、非生产设备范围和停止方法。不能为了取得设备连接而暂时关闭所有鉴权。

## 失败和升级

- 建议每个问题最多3轮有证据的修复；超过或涉及协议/安全变更向裁判升级。
- 云预算为最多3轮、每轮ASR≤1/LLM≤2/TTS≤1；还须用户给出金额/账户配额上限。没有预算不运行live。
- 单请求/录音/队列限制遵循spec；不得无限等待、重试或分配。
- 需要旧实现知识时提交具体问题与本仓库失败证据，裁判补充资料。
- 不把“固件不支持”变成降低要求，不自动切到WS、不私自升级固件。

## 给独立验收Agent

使用新会话/隔离工作区，读取批准的规格和固定候选commit或差异快照；不继承实现者的旧项目上下文。

重新运行offline，检查每条要求到测试和实现的映射；授权条件充分时再独立执行live/hardware。自动PR审查仅作为线索，需要复现或代码证据确认。

优先检查可信Broker身份、跨设备ACL、重连代次、UDP无认证限制、notify Idle生命周期、MCP请求关联、取消和日志秘密。

报告具体问题、严重性、复现、相关要求和证据。修复后重新验收最终版本；不得只依据实现者总结认定通过。

## 裁判输出

最终判定为通过、不通过或待验证/阻塞，附：

- R01–R12与全部A/L/H用例的逐项状态。
- 真实与模拟证据、固件版本、库版本和已批准例外。
- 尚未解决的兼容性/安全问题及M1前置决策。
- 是否允许进入M1；M0通过不自动批准部署或新阶段实现。
