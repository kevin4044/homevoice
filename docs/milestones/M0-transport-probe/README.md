# M0：MQTT + UDP 技术验证交接包

版本：`M0-v0.1`。状态：规格草案，待用户批准后交给编码负责人。本文档包未实现探针，未完成模拟、云服务或真实硬件验收。

用户已指定本期仅采用 MQTT 控制面 + UDP 音频；设备 WebSocket 接入不在范围内。HTTPS 仍用于安全配置下发、通知音频和后续 OTA，远程 MCP 可使用 HTTP 传输，两者不等于设备 WebSocket 路线。
