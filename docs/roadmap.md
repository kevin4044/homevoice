# Homevoice 产品路线图

日期：2026-10-22。本文定义长期方向，不是直接可执行的编码计划；所有阶段均未实施或验收。

## 发布顺序

协议验证 → 安全与设备生命周期 → 可靠语音 → 当前设备 Agent → HA 与房间 → 家庭 MVP → 通知/OTA/主题 → 记忆与扩展。

先服务一个家庭、一个管理员。模型和语音配置保持简单，家人不需要理解 MCP 或厂商参数。

## M0：协议与技术可行性

验证真实固件的鉴权、HELLO、音频格式、双向播放、打断与重连；验证 Go 模型工具调用和 MCP 客户端；明确音量、亮度、主题、通知、HTTPS OTA、验签和回滚支持。

**验收：** 隔离环境内完成真实设备演示，记录固件版本、报文和时延；明确需固件改造的能力，关键路径不靠猜测。

**门槛：** 在此阶段决定音频依赖和凭据写入方案；不公开部署无鉴权原型。

## M1：安全与设备生命周期

建立服务骨架、数据库迁移、管理员初始化与鉴权、短期一次性配对、逐设备凭据、WSS 认证、禁用/删除吊销、资源限制和最小审计。

**验收：** 未授权管理请求失败；未知或已撤销设备拒绝接入；删除立即断连且旧凭据不能重连；配对不可重放；密钥不出现在日志和常规响应中。

## M2：可靠语音链路

接入一个 ASR/LLM/TTS 配置；定义收音、处理、播放、打断状态；有界音频队列、超时、取消、有限重试和费用限制。

**验收：** 反复打断、重连和慢客户端测试不产生持续资源增长；上游故障明确反馈；记录端到端 p50/p95。默认不录音。

## M3：内部 Agent 与当前设备控制

实现有界工具循环和能力发现，音量/亮度工具绑定当前会话；校验参数，处理超时、取消、迟到结果；只提供实际固件支持的工具。

**验收：** 两台设备并发不串控制；模型不能自由替换设备目标；旧连接调用不能发送到新连接；未确认执行不宣称成功。

**发布：** 安全技术 Alpha，仅管理员验证。

## M4：HA 与房间控制

通过私网 MCP 接入 HA；映射小智到 HA Area；按获准实体/服务执行；当前房间默认语义，歧义询问；固定自动化复用 HA Scene/Script。

**验收：** 房间和实体正确；越权拒绝；区分小智自身亮度与房间灯光；HA 不可达不误报成功；本地自动化不依赖云端存活。

第一版不开放开门、车库门、解除报警等高风险操作。

## M5：家庭 MVP 与运维

提供设备状态、名称、房间、音量和免打扰界面；管理员维护入口独立授权；增加监控、一致性备份、恢复和应用回退。

**验收：** 家人无需技术配置即可使用；通过恢复演练、预期设备数及约两倍余量负载测试、72 小时混合稳定性测试；达到 M0/M2 实测后约定的时延标准。

**发布：** 家庭 MVP，前置安全门槛全部通过。

## M6：通知与日常体验

独立授权的 HA 通知入口，设备/房间定向，明确多设备规则；去重、有效期、忙碌队列或拒绝、离线、免打扰、音量策略与短期 HTTPS 音频访问。

**验收：** 不重复轰炸、不跨设备泄露、不补播过期通知；状态准确，固件无法确认播放时不承诺已播放。

## M7：OTA 与主题

固件版本、来源、摘要、板型与大小校验；管理员授权发布、认证下载、单台灰度和升级结果；仅提供硬件支持的主题。

**验收：** 未授权或不兼容更新被拒绝；失败不扩散；真实验证恢复能力。服务端摘要不替代设备端验签；固件缺少验签/回滚时明确限制，不承诺无人值守安全升级。

M6/M7 可按实际需求调整顺序，均依赖 M5 及 M0 的硬件能力验证。

## M8：受控记忆

有限最近对话、结构化任务状态、经确认的家庭/房间偏好、来源和生命周期；查看、修改、删除及按需上下文加载。

**验收：** “再亮一点”目标正确；删除后不可检索；旧记忆不覆盖实时状态或权限；未认证个人身份不读取个人私密记忆。

短期任务引用在 M3/M4 做最小支持，长期偏好不是 MVP 前置条件。

## M9：按需 Skills 与知识库

优先 HA Scene/Script；必要时增加受限、版本化 Skill；文档检索从简单方案开始，有质量需求再引入向量/混合检索；多步骤依赖确有价值时才引入 DAG。

**验收：** Skill 越权拒绝、部分失败可解释；知识回答可引用来源并承认未知；文档内容不能成为执行权限。

不允许模型生成并执行任意代码或 shell。

## 执行与迁移

- 每阶段启动前按[交接流程](governance/milestone-workflow.md)批准自包含规格和验收包。
- 只有规格负责人提取旧实现知识；其他 Agent 遵循[知识边界](governance/agent-principles.md)。
- 新服务先接入一台设备，旧服务保持可回退；迁移重新配对，不复制旧共享秘密。
- 不同时对真实 HA 写操作做双写对比；最后关闭旧入口、吊销旧凭据。
- M0 后依据固件改造和实际开发能力安排日历工期，不承诺未经验证的固定周数。
- 不做飞书等渠道、多租户、编程 Agent、声音克隆或海量模型配置平台。
