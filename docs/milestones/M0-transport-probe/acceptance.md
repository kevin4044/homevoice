# M0 验收标准

版本：`M0-v0.1`，待批准。这些入口和测试由编码阶段实现，当前仓库尚不能执行。裁判检查固定候选版本和实际输出，不接受只写“测试通过”。

## 验收入口约定

| 计划入口 | 内容 | 授权与结果 |
|---|---|---|
| `make verify-m0` | 格式、静态检查、race、纯协议/模拟集成、脱敏报告 | 无真实设备或云服务调用；通过仅算离线通过 |
| `make verify-m0-live` | 一个获准云配置、远程 MCP 只读探针 | 缺少授权/配置以非零退出并标记阻塞 |
| `make verify-m0-hardware` | 指定真机、MQTT/UDP/HTTPS、语音、Idle notify、MCP 枚举 | 需明确设备与操作授权；缺失不能跳过后返回成功 |

基础命令应包含 `go test -race -count=1 ./...`、`go vet ./...` 和不修改文件的格式检查；具体版本和原生依赖由 T0 记录。

单项状态为通过、失败、未执行、阻塞或有理由的不适用。必需项不能通过“不适用”绕过。

## 离线验收矩阵：全部必需

| ID | 对应规格 | 场景与判定 |
|---|---|---|
| A01 | R01 | 从干净的新仓库环境运行入口；无旧仓库路径或源码依赖，记录 Go/原生库版本 |
| A02 | R02 | 正确凭据成功，空/错误/未知凭据失败；未鉴权连接不创建设备/音频会话 |
| A03 | R03 | A/B 发布同一上行主题仍正确归属；A payload 声称 B 不能改变身份 |
| A04 | R03 | A 订阅 B/#/+、发布管理/其他主题、retained 控制均拒绝；下行仅到获准订阅 |
| A05 | R02–R04 | 重连 A 替换旧连接，旧关闭回调不能清除新连接；旧消息不影响新会话 |
| A06 | R02 | MQTT 3.1.1 基本握手、QoS 0/1、心跳/断开； malformed/超限报文有界拒绝 |
| A07 | R04 | 两设备 HELLO 的 key/SSRC/协议标识不同；重 HELLO 失效旧 UDP 和请求；随机源可注入测试但生产用 crypto/rand |
| A08 | R05 | 公开向量逐字节匹配；解密必须使用包头而非固定 nonce，模板保留正确 |
| A09 | R05 | 短头、长度不符、>1500、错误 type/flags、未知 SSRC 拒绝；空载荷不送解码器 |
| A10 | R05 | 序列 1、3、2、3：前三包在窗口内可接收，重复 3 拒绝；窗口外旧包拒绝；首次 0 按协商明确处理 |
| A11 | R05 | peer 建立后另一地址不能覆盖；新 HELLO 才能更换；测试指出首次锁定不构成认证 |
| A12 | R05 | 出站同 socket；未建立 peer 不发送；序号从 1，失败不回退，回绕拒绝；时间戳非零 |
| A13 | R05/R12 | 篡改向量可解密且明文改变，报告明确“无认证”；记录相同 key/计数器复用风险，禁止宣称 UDP 完整性通过 |
| A14 | R06 | 合成 PCM 正弦/静音经 Opus 编解码输出非空、有限且时长匹配；上下行参数独立；样例密文字节不作为 Opus |
| A15 | R06 | 不齐帧 PCM 跨分块不丢样，奇数字节有明确处理，尾帧有验证；连续编码保持状态 |
| A16 | R07 | 假时钟验证 start→settle→首帧、5 帧预缓冲与尾等待；停顿恢复不将剩余帧全部突发发送 |
| A17 | R07 | manual/auto/realtime 收口有界；播放 abort 在处理后 200 ms 内停止本轮新发送（已入网数据除外） |
| A18 | R07/R08 | abort 保留有效音频会话、下一轮可收音；goodbye 清音频不清 MQTT；断线最终清两者 |
| A19 | R07 | 100 次模拟 HELLO/abort/goodbye/重连后注册表、待请求和任务归零；队列≤64，overflow 有计数 |
| A20 | R08 | MQTT 在线且无 UDP 时能发送 notify；busy/offline 明确失败；不能把 published 当 played |
| A21 | R09 | 初始化、协议协商、所需 initialized 通知、工具分页成功；循环 cursor、超页/工具数/报文拒绝 |
| A22 | R09 | A/B 同时有相同 request ID 不串响应；超时、重复、旧连接/会话响应不能完成新请求 |
| A23 | R09 | JSON-RPC error 与 isError 都算失败；完整 schema 保留，不支持工具不暴露 |
| A24 | R10 | 模拟 LLM 只发当前设备音量；异常类型/范围/额外 device_id 拒绝；工具目标来自会话 |
| A25 | R10 | 模型超过调用/工具次数、上游超时、取消后响应均收口；未确认执行不回答成功 |
| A26 | R11 | 模拟远程 MCP 成功、401、超时、错误证书/目标权限；不会调用真实 HA 写工具 |
| A27 | R12 | 除 loopback/授权私网外启动拒绝；TLS 不跳过验证；错误时无自动明文/WS 降级 |
| A28 | R12 | 用合成秘密做日志捕获，密码/key/完整音频及私人内容不出现；缺少 live/hardware 条件必须非零阻塞 |

A14 不比较有损 Opus 的字节相等或主观音质。使用采样数/时长、能量非零/静音有界、解码错误检查；精确容差由编码负责人依据 codec delay 记录并交裁判确认，不删除异常测试。

## 授权云/远程 MCP：全部必需

| ID | 场景与判定 |
|---|---|
| L01 | 选定模型对固定无私人信息的请求产生合成音量调用，模拟设备执行并返回结果；≤2 模型请求、≤1 工具 |
| L02 | 指定 ASR 识别合成测试音频，TTS 返回可解码音频；记录媒体格式、延迟和错误，不调用额外供应商 |
| L03 | 选定远程 MCP 传输完成初始化/只读查询，鉴权有效；测试失败明确报告，不采集未授权家庭信息 |

真实服务不一定每次输出相同文本，只检查结构、参数、目标隔离与结果语义。最多 3 轮，不无限尝试直到成功；费用按用户批准预算，缺少预算先阻塞。

## 真实设备：全部必需

| ID | 场景与判定 |
|---|---|
| H01 | 记录固件/板型、精确 MQTT 配置和安全连接行为；拒绝错误凭据，若需隔离明文例外须单独授权并标记限制 |
| H02 | 至少一台设备完成 HELLO、UDP 上行解码、下行真实可听播放；不使用旧服务代做 |
| H03 | 至少 3 次播放打断和 3 次重连后能继续使用；记录上行序列/时间戳及 NAT 行为 |
| H04 | 回到 Idle、UDP 会话已释放时，至少 3 次 MQTT notify 下载并播放无敏感测试音频；记录通知延迟 |
| H05 | 通过目标设备 MQTT 枚举真实 MCP 工具/schema，完成初始化并确定音量及亮度能力或缺失项 |
| H06 | 填写兼容性表与后续 OTA/主题/凭据能力；未知项明确来源缺口，不假装固件验签/回滚存在 |

M0 不默认执行真实音量/亮度变更或 OTA。H05 以发现能力为主；当前设备写操作的完整功能验收属于 M3。

端到端语音和通知的外部观察不能由“send 成功”代替。可用脱敏文字观察记录；音频/照片留存需要额外授权。

## 时延与决策

模拟测试可检查逻辑时间，硬件记录单调时钟的输入结束、ASR结束、模型首 token/工具、TTS首帧、UDP首发和已确认/观察播放时间。样本不足只报告样本数、原始值与范围，不声称可信 p95。

M0 不预设最终 SLA；若能收集≥20 个同条件样本才报告分位数。用户未批准更多云轮次时不得为凑统计样本扩大预算。

最终报告逐项映射 R01–R12，区分兼容性与安全。Broker 身份来源、通知/MCP缺失、凭据写入不可行或公网安全方案未定，均需裁判明确决策后才能宣布 M0 通过。
