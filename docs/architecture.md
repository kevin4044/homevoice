# 架构与安全边界

本文描述拟议设计，不表示组件已实现或协议兼容性已验证。

## 系统路径

```text
小智设备
  │ WSS + 设备鉴权
  ▼
Homevoice Go 服务 ── 云端 ASR / LLM / TTS
  │
  │ 私有网络内的鉴权 MCP 通信
  ▼
家庭 HA MCP 服务或受限适配器
  │
  ▼
Home Assistant → 获准的设备与场景
```

前端为 React/TypeScript；SQLite 保存设备、映射、授权状态、通知配置与必要审计。管理入口限定可访问范围；HA 不直接暴露公网。

## 模块责任

| 模块 | 职责 |
|---|---|
| 设备与鉴权 | 配对、凭据、撤销、连接、能力发现 |
| 语音会话 | 音频、状态机、背压、打断和取消 |
| 内部 Agent | 模型客户端、有限上下文和有界工具循环 |
| 工具执行 | 当前设备路由、HA 路由、权限和参数校验 |
| 家庭信息 | HA Area/实体查询、小智房间映射 |
| 通知 | 授权、去重、有效期、忙碌和免打扰 |
| OTA | 来源、兼容、授权分发、灰度和状态 |
| 记忆与检索 | 按需增加，不在首版构建通用平台 |

保持模块化单体，不提前拆微服务、引入 Redis 或独立 Node.js 后端。

## 核心不变量

1. 设备 ID 是标识，不是身份证明；会话来自成功鉴权的连接。
2. 当前设备工具不允许模型任意填写目标设备，执行器从会话获取目标。
3. 连接实例与操作关联，断线、取消、撤销后旧操作不能落到新连接。
4. 删除设备必须撤销访问并终止连接，不仅删除目录记录。
5. 模型、记忆、Skill 和检索文档不能授予设备操作权限。
6. 执行器验证工具、实体、参数类型与范围；允许列表由服务端管理。
7. 已接收、已发送、已确认、失败和结果未知必须区分。
8. 连接、音频队列、上游调用、工具迭代、重试和总耗时必须有界。
9. 音频和完整对话默认不持久化，凭据与私人内容不进入日志。
10. HA 实时状态和配置是事实来源，LLM 记忆不能覆盖它们。

## 固件与部署边界

M0 必须验证凭据写入、WSS 证书、设备 MCP、音频、通知与 OTA。服务器不能独自提供固件缺失的验签、升级回滚、主题或结果确认能力。

M0 探索仅在隔离测试环境进行。未完成安全验收前不将原型公开部署，不操作敏感真实家电。

工具链版本、模型/语音供应商、MCP 传输和具体依赖在验证后通过设计决策记录锁定；当前不宣称已具备这些能力。
